# Көшелерге атау беру туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы N 148 "Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы" Заңының 35-бабының 2-тармағына және Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы N 4200 "Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы" Заңының 14-бабының 4 тармақшасына,Қазақстан Республикасы Үкіметінің 2005 жылғы 21 қаңтардағы N 45 "Қазақстан Республикасындағы мемлекеттік ономастикалық жұмыс тұжырымдамасы туралы" қаулысына сәйкес Үшқұдық селолық округінің әкімі ШЕШІМ ЕТЕДІ:

1. Үшқұдық селолық округі халқының пікірін ескере отырып Ақсазды, Жерұйық ауылдарының көшелеріне атау берілсін.

   1.1. Ақсазды ауылының көшелеріне:

   N 1 көшеге Еңбекші.

   N 2 көшеге Орталық.

   N 3 көшеге Мектеп.

   N 4 көшеге Жасыл.

   1.2. Жерұйық ауылының көшелеріне:

   N 1 көшеге Бірлік.

   N 2 көшеге Бейбітшілік.

2. Осы шешім алғаш ресми жарияраланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Үшқұдық селолық округінің әкімі**

**С. Балгожин**
