# "Көктау селолық округінің көшелері мен құрылымдық бөліктеріне атау беру туралы"

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы № 148 «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Заңының 35 бабының 2 тармағына, Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы № 4200 «Қазақстан Республикасының әкімшілік-аумақтық құрылымы туралы» Заңының 14 бабына сәйкес, Көктау селолық округі халқының пікірін ескере отырып, Көктау селолық округінің әкімі ШЕШТІ:

<a id="p1"></a>

1. Осы шешімге қосымша ұсынылған схемалық картаға сәйкес орналасқан Көктау селолық округінің келесі көшелеріне мынадай атаулар берілсін:

   «Нұрлы көш» көшесі;

   Абай көшесі;

   Ленин көшесі;

   Гагарин көшесі.

<a id="p2"></a>

2. Осы шешімге қосымша ұсынылған схемалық картаға сәйкес орналасқан Көктау округінің құрылымдық бөліктеріне (қыстаулар) мынадай атаулар берілсін:

   Жангелді қыстауы;

   Талдысай қыстауы;

   Жылан төбе қыстауы;

   Көшенсай қыстауы.

<a id="p3"></a>

3. Осы шешімнің орындалуы «Көктау селолық округі әкімінің аппараты» мемлекеттік мекемесінің бас маманы А. И. Рсалинге тапсырылсын.

<a id="p4"></a>

4. Шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p5"></a>

5. Осы шешім алғаш ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Көктау селолық округінің әкімі**

**Б. Жұмағалеев**
