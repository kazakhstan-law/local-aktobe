# Алтықарасу, Еңбекші, Сартоғай ауылдарының көшелерін атау туралы

> *Ескерту. Шешімнің деректемелерінде және бүкіл мәтін бойынша "селолық", "селосының" сөздері "ауылдық", "ауылының" сөздерімен ауыстырылды - Ақтөбе облысы Темір ауданы Алтықарасу ауылдық округі әкімінің 27.09.2016 № 16 шешімімен (алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі).*

Қазақстан Республикасының 2001 жылғы 23 қаңтар N 148 "Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы" Заңның 35 бабының 2 тармағының, Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы N 4200 "Қазақстан Республикасының әкімшілік аумақтық құрылысы туралы" Заңының 14 бабының 4 тармағына сәйкес Алтықарасу, Еңбекші, Сартоғай халқының пікірін ескере отырып Алтықарасу ауылдық округі әкімі ШЕШІМ ЕТЕДІ:

1. Алтықарасу ауылының атаулары жоқ

   N 1 көшеге Қызыл керуен

   N 2 көшеге С. Аманғосов

   N 3 көшеге Қарабас

   N 4 көшеге Астана

   N 5 көшеге Қарағанды

   N 6 көшеге Тасқабақ

   Еңбекші ауылының атаулары жоқ

   N 1 көшеге Еңбекші

   N 2 көшеге Шығырлы

   N 3 көшеге Шилітоғай

   N 4 көшеге Қаракемер

   Сартоғай ауылының атаулары жоқ

   N 1 көшеге Нұрлепес ата

   N 2 көшеге Мектеп

   N 3 көшеге Абай деген атаулар берілсін.

2. Осы шешім әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді және алғашқы ресми жарияланған күннен бастап он тізбелік күн өткеннен кейін қолданысқа енгізіледі.

**Алтықарасу ауылдық округі әкімі:**
