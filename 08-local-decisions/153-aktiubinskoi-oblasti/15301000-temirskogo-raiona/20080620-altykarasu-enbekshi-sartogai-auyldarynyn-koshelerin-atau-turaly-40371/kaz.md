# Алтықарасу, Еңбекші, Сартоғай ауылдарының көшелерін атау туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтар N 148 "Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы" Заңның 35 бабының 2 тармағының, Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы N 4200 "Қазақстан Республикасының әкімшілік аумақтық құрылысы туралы" Заңының 14 бабының 4 тармағына сәйкес Алтықарасу, Еңбекші, Сартоғай халқының пікірін ескере отырып Алтықарасу селолық округі әкімі ШЕШІМ ЕТЕДІ:

1. Алтықарасу селосының атаулары жоқ

   N 1 көшеге Қызыл керуен

   N 2 көшеге С. Аманғосов

   N 3 көшеге Қарабас

   N 4 көшеге Астана

   N 5 көшеге Қарағанды

   N 6 көшеге Тасқабақ

   Еңбекші ауылының атаулары жоқ

   N 1 көшеге Еңбекші

   N 2 көшеге Шығырлы

   N 3 көшеге Шилітоғай

   N 4 көшеге Қаракемер

   Сартоғай ауылының атаулары жоқ

   N 1 көшеге Нұрлепес ата

   N 2 көшеге Мектеп

   N 3 көшеге Абай деген атаулар берілсін.

2. Осы шешім әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді және алғашқы ресми жарияланған күннен бастап он тізбелік күн өткеннен кейін қолданысқа енгізіледі.

**Алтықарасу селолық округі әкімі:**

**Е. Төлеуов**
